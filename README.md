# Loki | Portfolio
All files sit in one place, no folders. Upload every file to the root of your GitHub repo (index.html must be there).
- Skills and project cards: top of `main.js`.
- Colours: the variables at the top of `style.css` and `shared.css`.
- Live code viewer reads `sources.js`. After editing a project page, run `python3 build-sources.py`.
- Library system: replace `library.html` with your own code (keep the two `shared` lines in its head).
